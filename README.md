🚗 Uber Trip Analysis - End-to-End Power BI Project
📌 Project Overview
This project was developed to analyze Uber trip data to measure booking trends, revenue streams, and operational efficiency. Three main dashboards were created by processing raw data, enabling stakeholders to make data-driven strategic decisions.

🛠️ Key Features & Technical Implementation

Dynamic Measure Selector: A dynamic measurement structure has been established that allows users to instantly switch between Total Bookings, Total Booking Value, and Total Trip Distance.

Time Series & Demand Analysis: Area graphs analyzing demand in 10-minute periods and Heatmap (Matrix) visualizations showing weekly/hourly intensity have been designed.

Advanced Data Modeling: The Inactive Relationships (USERELATIONSHIP) method is used to manage the relationships between departure and arrival locations in a single model.

UX/UI Enhancements: Drill-Through feature for detailed data analysis, report clearing buttons, and dynamic headings are integrated.

📊 Analyzed KPIs

Total Bookings & Value: Total number of trips and total revenue generated.

Trip Efficiency: Analysis of average trip distance, duration, and revenue per unit.
